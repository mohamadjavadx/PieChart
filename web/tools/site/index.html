PieChart for the web

An animated, accessible donut chart: the look and features of the Android library, drawn with SVG. A web component, a React component and a plain class, with no dependencies.

Tap a slice, or tap the gray one to open it. With the keyboard: Tab, then the arrow keys, Enter and Escape.

npm install @mohamadjavadx/piechart
Settings playgroundThe Android demo's controls: segments, hole, corners, gap, grouping, dimming. The <pie-chart> elementAttributes, properties and events, in plain HTML. The React componentData changes that morph, and callbacks.
